# CollagrCms-core - Backend для генерации коллажей

Backend сервис для генерации коллажей из изображений с использованием Pillow.

## Описание

Сервис принимает запросы с изображениями и метаданными композиции, выполняет серверную обработку изображений и возвращает готовый коллаж.

## Технологии

- **FastAPI** - HTTP API
- **Pillow (PIL)** - обработка изображений
- **Pydantic** - валидация данных

## API Endpoints

### Коллажи

- `POST /v1/collage/` - Создание коллажа из выбранных изображений
  - Параметры: `list_id` (список ID изображений), `is_price` (флаг отображения цены)
  - Возвращает: JPEG файл коллажа

- `GET /v1/collage/` - Получение всех товаров для коллажа
  - Возвращает: JSON с информацией о товарах и категориях

- `GET /v1/collage/batch/` - Создание коллажа из пакета товаров
  - Параметры: `batch_size`, `start_index`, `is_price`
  - Возвращает: JPEG файл коллажа

- `GET /v1/collage/batch/all/download/` - Скачивание всех коллажей в ZIP-архиве
  - Параметры: `batch_size`, `is_price`
  - Возвращает: ZIP архив с коллажами

- `GET /v1/collage/batch/all/` - Получение информации о всех коллажах
  - Возвращает: JSON с информацией о доступных коллажах

- `GET /v1/collage/batch/status/` - Получение статуса пакетной обработки
  - Возвращает: JSON со статусом обработки

- `GET /v1/collage/batch/info/` - Получение информации о текущем пакете
  - Параметры: `start_index`, `batch_size`
  - Возвращает: JSON с информацией о пакете

- `POST /v1/collage/cleanup/` - Очистка временных файлов
  - Возвращает: JSON с результатом очистки

## Запуск

```bash
# Установка зависимостей
uv sync

# Запуск в режиме разработки
uv run --env-file cfg/.env uvicorn src.__main__:app --host 0.0.0.0 --port 8000 --workers 4 --reload

# Запуск в продакшене
uv run --env-file cfg/.env uvicorn src.__main__:app --host 0.0.0.0 --port 8000 --workers 4
```

## Конфигурация

Создайте файл `.env` на основе `cfg/example.env`:

```bash
cp cfg/example.env cfg/.env
```

Основные параметры:
- `SERVER_HOST` - хост сервера (по умолчанию: 0.0.0.0)
- `SERVER_PORT` - порт сервера (по умолчанию: 8000)
- `DEBUG` - режим отладки (по умолчанию: False)
