# CollagrCms - Система управления коллажами

## Описание

CollagrCms - это веб-приложение для создания коллажей из изображений товаров с наложением текстовой информации (название, цена, описание) в формате A3 (горизонтальный).

## Основные возможности

### Создание коллажей
- **Фиксированный формат A3 (горизонтальный)**: все коллажи создаются в стандартном формате A3 (420×297 мм) в горизонтальной ориентации
- **Динамическое количество изображений**: от 1 до 9 изображений
- **Автоматический расчет сетки**: система автоматически выбирает оптимальную компоновку
- **Адаптивные размеры ячеек**: размеры изображений автоматически подстраиваются под количество
- **Наложение текста**: цена, название и описание товара накладываются на каждое изображение

### Схемы сеток

| Количество изображений | Сетка | Описание |
|----------------------|-------|----------|
| 1 | 1×1 | Одно изображение по центру |
| 2 | 2×1 | Два изображения в ряд |
| 3 | 3×1 | Три изображения в ряд |
| 4 | 2×2 | Квадратная сетка 2×2 |
| 5 | 3×2 | Два ряда: 3 + 2 изображения |
| 6 | 3×2 | Два ряда по 3 изображения |
| 7 | 4×2 | Два ряда: 4 + 3 изображения |
| 8 | 4×2 | Два ряда по 4 изображения |
| 9 | 3×3 | Квадратная сетка 3×3 |

## API Endpoints

### Создание коллажа
```
GET /collage/?list_id=1&list_id=2&list_id=3
```

**Параметры:**
- `list_id` (обязательный): ID изображений для коллажа (от 1 до 9 значений)

**Примеры:**
```bash
# Коллаж из одного изображения
GET /collage/?list_id=1

# Коллаж из трех изображений
GET /collage/?list_id=1&list_id=2&list_id=3

# Коллаж из девяти изображений
GET /collage/?list_id=1&list_id=2&list_id=3&list_id=4&list_id=5&list_id=6&list_id=7&list_id=8&list_id=9
```

### Получение списка товаров
```
GET /products/
```
Возвращает список всех товаров с URL изображений для фронтенда.

### Создание товара
```
POST /products/
```
Создает новый товар с загруженным изображением.

### Получение изображения
```
GET /media/{image_id}
```
Возвращает файл изображения по ID.

## Технические детали

### CollageCreator
Основной класс для создания коллажей:

```python
from src.core.collage_creator import CollageCreator

creator = CollageCreator()
result_path = creator.create(image_models, "output.jpg")
```

**Особенности:**
- Фиксированный формат A3 (горизонтальный) (4961×3508 пикселей при 300 DPI)
- Автоматический расчет размеров сетки и ячеек
- Масштабирование изображений с сохранением пропорций
- Наложение текстовой информации
- Рамка вокруг коллажа
- Высокое качество JPEG (95%)

### Параметры коллажа
- **Формат**: A3 (горизонтальный) (4961×3508 пикселей при 300 DPI)
- **Отступы от краев**: 80 пикселей
- **Отступы между ячейками**: 50 пикселей
- **Толщина рамки**: 40 пикселей
- **Цвет фона**: (53, 3, 61) - темно-фиолетовый
- **Цвет рамки**: (126, 100, 126) - серо-фиолетовый
- **Размеры ячеек**: автоматически рассчитываются в зависимости от количества изображений

### Примеры размеров ячеек
- **1 изображение**: ~4801×3348 пикселей
- **2 изображения**: ~2350×3348 пикселей каждое
- **3 изображения**: ~1550×3348 пикселей каждое
- **4 изображения**: ~2350×1654 пикселей каждое
- **7 изображений**: ~1150×1654 пикселей каждое
- **9 изображений**: ~1550×1100 пикселей каждое

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте базу данных:
```bash
# Создайте таблицы
python -m src.database.queries.init_db
```

3. Запустите приложение:
```bash
python -m src
```

## Тестирование

Запустите тесты:
```bash
pytest tests/
```

Тесты покрывают:
- Создание коллажей с разным количеством изображений
- Расчет размеров сетки и ячеек
- Обработку ошибок
- Валидацию входных данных
